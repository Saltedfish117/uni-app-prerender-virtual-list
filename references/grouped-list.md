# 分组吸顶与跳转

参考 [容器滚动模板](../assets/scroll-view-example.md)，仅将其 `vue` 代码块保存为 `ScrollViewExample.vue`。示例将合成组头与条目扁平化，固定高度的 `scroll-view` 是唯一滚动所有者。它展示原生标签实现的分组 tabs、吸顶副本和跨窗口选择。

## 组头与状态

组头带 `role: 'group-header'` 和稳定 `groupId`；条目可带同组 ID。组头也是正常布局节点。活动组由局部滚动位置加 topInset 与组头 top 比较，吸顶在越过第一组头 bottom 后出现。

吸顶副本位于滚动内容之外，与实际组头读取同一状态。默认没有下一个组头推挤动画。复制视觉结构时不能把组头的选择状态只存于临时组件实例。

选择集合位于页面，按完整数据范围计算全选/组选择，不从 `visibleList` 推导。Vue 2 中 Set 本身不是响应式视图依赖；显式更新选择版本或计数，并触发当前窗口展示刷新。数据删除后修剪无效选择，筛选是否保留隐藏项选择由实际需求决定。

## 程序滚动

1. 测量 ready 后才接受分组跳转，使用 `getGroupOffset(groupId)` 取得目标局部位置。未知组返回 null，不跳到猜测位置。
2. 开始时锁定活动组。页面滚动目标为 `listTop + localTarget`；容器目标为 `listOffsetInContent + localTarget`，最后按原生滚动可达范围限制。
3. 以跳转版本号识别最近请求；完成事件或有限时间收尾后，查询实际滚动位置，再调用 `endProgrammaticScroll`。请求值不等于实际值，尤其是在内容不足一屏时。
4. 新跳转、隐藏、重新测量或卸载要作废旧的收尾计时器和异步回调。不能在旧 finally 中解除新跳转的锁。

示例可以使用非动画跳转以减少平台动画差异，但仍必须真实回读。加入动画时按目标平台的完成语义调整适配层，不让纯控制器决定动画完成时刻。

事件静默或触底时校正原生位置，仍需保持活动组锁定规则；查询版本不能覆盖较新的跳转或筛选。程序绑定值与目标相同时可使用近邻值触发更新，收尾始终读取实际值。筛选回顶的近零切换及有界确认见 [空白诊断](scroll-blank-diagnosis.md#筛选先回顶再刷新)。

## 末组补高

为了让末组到达遮挡区域下方，额外尾部空间至少为：

`max(0, lastGroupTop - topInset + viewportHeight - totalHeight - existingTrailingSpace)`

此空间在控制器占位之后，单独参与实际滚动高度。它不是可见节点，也不改变控制器 totalHeight。固定底部栏实际遮挡需另计入页面布局，不能复制任何页面特有的常数。

搜索、分页与组顺序由外层数据流程管理。空组是否保留组头属于产品行为，不由虚拟化替页面作决定。
