# 等高列表

适合所有行都受相同 CSS 高度约束的列表。行内文字截断、图片容器尺寸、边框和内边距必须确保总高一致。`box-sizing: border-box` 能让声明高度包含边框；外部 margin 不属于 `boundingClientRect.height`。

阅读 [页面滚动模板](../assets/page-scroll-example.md)，仅将其 `vue` 代码块保存为 `PageScrollExample.vue`。它使用合成条目，展示预渲染、页面坐标转换、追加数据及相同窗口内的内容更新，不请求服务端数据。

## 测量与计算

1. 隐藏测量层置于正式列表包含块内，以 `width:100%` 继承内容宽度并保留自然高度；临时挂载一条真实结构的行。参见 [同宽样本](integration.md#同宽样本)。
2. 页面 ready 且显示后等待 `nextTick`，查询实测行高、列表位置、视口滚动位置与视口尺寸。
3. 提交 `rowHeight` 与已加载节点。容器撑开总高，只有窗口中的行绝对定位。

对于统一高度 h、条目数 n、局部滚动位置 s、视口 v 和缓冲 b，候选起点为 `floor((s-b)/h)`，终点为 `ceil((s+v+b)/h)`，均限制在 `[0,n]`。条目 top 为 `index*h`，总高为 `n*h`。边界 O(1)，生成 k 个可见节点 O(k)，不能把整次更新称为 O(1)。

## 更新时机

- 分页追加：保留原分页流程；使用新节点提交布局，即使窗口起止不变，也刷新可见数据。
- 刷新/筛选：由页面决定保位还是回顶，并提交对应的实际滚动位置；不在控制器中偷偷重置。
- 宽度、字体或样式影响行高时：重新测量。即使 CSS 写了 rpx，也不能将 rpx 数值直接当成 px。
- 页头展开导致列表移动：更新文档 listTop 和局部滚动值；若行宽没变，无需重新生成所有布局 rect。

不要仅因第一条看上去正常就选择等高模式。若另一行能产生额外换行、额外操作栏或异步展开，应约束版式或选择其他高度策略。
